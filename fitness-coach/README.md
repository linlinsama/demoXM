# 双人健身教练

给两个人（我和男朋友）用的 AI 健身 + 饮食 + 体重工具。单个 HTML 页面，托管在 claude.ai 上作为 Artifact 运行：
数据存在 Artifact 自带的共享数据库里，AI 分析直接调用打开页面的人的 Claude，不需要服务器，也不需要 API Key。

## 功能

| 页签 | 做什么 |
|---|---|
| 今日 | 两人今日对比（摄入 / 目标、训练、体重 7 天变化）；当前成员的「能量账本」：还能吃多少、三大营养素进度；AI 生成「今天剩下几顿怎么吃」 |
| 训练 | 上传运动结束后的截图（可多张：总览、心率区间、分段等）→ Claude 读出时长、消耗、心率、配速、组数等数据，给出 0–100 评分、强度、心率区间分布、做得好的 / 要改进的、对目标的作用、下次训练安排、练后恢复和饮食 |
| 饮食 | 拍一餐（或外卖订单、营养成分表截图）→ 每样食物的份量、热量、蛋白质、碳水、脂肪，点评和改法；最近 7 天每日摄入条 |
| 身体 | 记录体重 / 体脂 / 腰围（也可以上传体脂秤截图自动识别，支持「斤」）；BMI（中国标准）、7 天 / 30 天变化、近 4 周速度、距目标；体重曲线（含 7 天平均和目标线）和两人对比曲线；AI 结合身高、体重、近 28 天饮食和训练做趋势分析 |
| 档案 | 两个人各自的性别、出生年份、身高、体重、目标（减脂 / 维持 / 增肌）、目标体重、日常活动水平、热量缺口；体重单位 kg / 斤 |

## 热量目标怎么算

- 基础代谢：Mifflin-St Jeor 公式。
- 日常消耗 = 基础代谢 × 日常活动系数（1.2 / 1.3 / 1.45 / 1.6，不含刻意训练）。
- 运动消耗：当天训练截图里的活动消耗按 80% 计入（手表普遍估高）。
- 目标摄入 = 总消耗 − 缺口（减脂）或 + 盈余（增肌）。缺口留空时自动取不训练日消耗的 20%，最多 500 kcal，且不让目标低于基础代谢；增肌默认 +300 kcal。
- 蛋白质：减脂 / 增肌 1.8 g/kg，维持 1.4 g/kg（BMI > 28 时按 BMI 25 对应体重算）；脂肪约 27% 热量，其余为碳水。

## 数据

存在 Artifact 的 `db` 能力里（集合：`profiles`、`weights`、`workouts`、`meals`、`advice`、`trends`）。
图片本身不保存，只保存一张约 300px 的缩略图和 AI 读出的结构化结果。

## 两个人怎么用

- 页面所有者一个人就能给两个人记录：顶部切换成员即可。
- 想让另一个人也在自己手机上记录：在 Artifact 的「分享」里用邮箱邀请对方，并设为**编辑者**（只读的查看者不能写入数据）。对方需要有 Claude 账号，AI 分析会使用对方自己的 Claude 用量。

## 本地预览

页面依赖 claude.ai 提供的 `window.claude`（`db`、`sample`）。直接用浏览器打开 `index.html` 会显示「需要在 claude.ai 中打开」，只能看到界面。
